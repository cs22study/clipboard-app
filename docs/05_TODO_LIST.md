## 🔥 當前優先待開發項目 (P0 & P1 Backlog - Phase 4)

### 1. HTML5 拖曳排序模組 (Drag & Drop Engine) - `P1`
- [ ] **同欄位上下拖曳**：在相同主題欄位內拖曳卡片卡位，自動重新計算 `order` 數值並非同步同步後端。
- [ ] **跨欄位左右拖曳**：將卡片從「主題 A」拖拉至「主題 B」，後端更新該卡片之 `topic` 欄位。
- [ ] **視覺效果**：拖曳時呈現半透明 Ghost 佔位符與藍色放置輔助線。

### 2. 前端 Canvas WebP 圖片智慧壓縮 - `P1`
- [ ] **本機尺寸壓縮**：使用者貼上或選取大圖（例如 > 1920px）時，利用 HTML5 Canvas 於瀏覽器端縮放至合適尺寸。
- [ ] **WebP 轉檔**：將 PNG / JPEG 轉換為 WebP 格式（品質 0.82），大幅減少 Base64 傳輸體積與 Google Drive 容量。
- [ ] **零伺服器負擔**：由客戶端算力負擔壓縮，保持 Google Apps Script 執行時間低於 1 秒。

### 3. 即時模糊搜尋與標籤點擊快篩 - `P1`
- [ ] **即時文字過濾**：在頂部搜尋列鍵入文字時，即時隱藏不符合之卡片，並將符合字元以黃色高亮標註。
- [ ] **標籤互動篩選**：點擊卡片上的任何 `#tag`，搜尋列自動填入該標籤並精確過濾。
- [ ] **一鍵清空**：搜尋列右側加入 `✖` 快速清除按鈕。

### 4. 卡片留言與回應討論串 - `P2`
- [ ] **留言折疊展開**：卡片底部新增「💬 留言 (N)」展開按鈕。
- [ ] **留言儲存**：於試算表規劃獨立 `Cards_Comments` 分頁或以 JSON 字串附加於第 14 欄。
- [ ] **免註冊快速回饋**：支援同伴留下姓名與短語回饋。
